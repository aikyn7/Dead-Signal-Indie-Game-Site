Behind the Concept

Although the game is currently a conceptual prototype, if we wanted to create it, we would do so using the GODOT engine. The goal was to convey the authentic aesthetic of a low‑poly game from the PSX era, combining tank control, fixed shooting angles, and resource management in a survival horror setting.

All the HTML and CSS on this website were written manually to reflect the dark, minimalist style typically found on indie game platforms such as itch.io.
